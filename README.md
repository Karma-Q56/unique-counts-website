# Unique Counts Project

## Overview
Unique Counts is a website dedicated to showcasing the services and expertise of Unique Counts Pty Ltd, a company specializing in cutting, processing, and installing various stone products. The website provides information about the company, its services, and a gallery of completed projects.

## Files Description

- **index.html**: The main HTML file containing the structure and content of the Unique Counts website. It includes sections for the header, hero, about, services, gallery, and contact information.

- **assets/css/styles.css**: This file contains the CSS styles for the website, defining the layout, colors, typography, and responsive design.

- **assets/js/script.js**: This file contains JavaScript code for interactive features such as mobile navigation toggle, smooth scrolling, contact form handling, and gallery slider functionality.

- **assets/images/img1.jpg**: An image used in the gallery section of the website.

- **assets/images/img2.jpg**: Another image used in the gallery section of the website.

- **assets/images/dumi.jpg**: An image used in the about section of the website.

- **assets/images/logo.png**: The logo image for the Unique Counts brand.

- **pages/services.html**: A separate HTML page dedicated to detailing the services offered by Unique Counts.

- **pages/gallery.html**: A separate HTML page showcasing the gallery of work done by Unique Counts.

- **pages/contact.html**: A separate HTML page containing contact information and a contact form for inquiries.

## Setup Instructions
1. Clone the repository or download the project files.
2. Open the `index.html` file in a web browser to view the website.
3. For development, you can modify the CSS in `assets/css/styles.css` and the JavaScript in `assets/js/script.js` as needed.

## Features
- Responsive design for optimal viewing on various devices.
- Smooth scrolling navigation for a better user experience.
- Interactive gallery slider to showcase images of completed projects.
- Contact form for inquiries, with validation and user feedback.
